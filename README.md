# AgileTour 中国社区官网

> AgileTour China Community Website · 敏捷之旅中国社区官方网站

## 中文说明

AgileTour 敏捷之旅中国社区官网，用于介绍社区使命、全球敏捷实践者网络、全国组织者聚会以及官方联系方式。

网站始于“连接实践者，让敏捷持续发生”的理念，聚焦敏捷实践经验分享、学习圈子建设和社区之间的长期连接。

### 主要内容

- 高端深色科技感首页
- AgileTour 中国社区品牌展示
- 社区发展数据与历史介绍
- 全球社区分布地图
- 2014–2019 全国组织者聚会照片墙
- 官方 Logo、微信公众号和视频号二维码
- 响应式布局，支持桌面端和移动端
- 平滑滚动、导航锚点和基础交互

### 技术栈

- HTML5
- CSS3
- Vanilla JavaScript
- SVG favicon
- 本地图片资源

### 项目结构

```text
agiletourchina/

```

### 本地预览

本项目是静态网站，不需要安装依赖。可以使用任意静态文件服务器预览，例如：

```bash
python3 -m http.server 4173
```

然后打开：

```text
http://localhost:4173/
```

也可以直接双击 `index.html` 查看页面。

## English Description

The AgileTour China Community website introduces the community mission, the global Agile practitioner network, national organizer gatherings, and official contact channels.

The website is built around the idea of connecting practitioners and helping Agile continue to happen through real-world practice sharing, learning circles, and long-term community connections.

### Key Features

- Premium dark technology-inspired homepage
- AgileTour China community branding
- Community history and milestone statistics
- Global community distribution map
- Photo gallery of national organizer gatherings from 2014 to 2019
- Official logo, WeChat account, and video account QR codes
- Responsive desktop and mobile layouts
- Smooth scrolling, anchor navigation, and lightweight interactions

### Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- SVG favicon
- Local image assets
